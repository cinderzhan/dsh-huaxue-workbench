# 花少2 · 花学工作台 第一版

面向日常工作、表达练习与角色化陪伴的 DSH Desktop 工作台。七位旅伴：毛毛姐、晴公主、静静子、陈大发、Luke、羊羊、爽子。提供原生 Agent 聊天、花学拆解、背景设置和「第八位嘉宾」场景续演。

这是待审核源码快照，不是已上架工作台或通用安装包。仅在 Windows 的 DSH Desktop 0.8.2 / Harness 0.1.2-rc.1 环境验证。源码授权暂未确定，不能按默认开源许可再分发；资源说明见 RIGHTS.md。

## 解决什么工作

面向需要起草工作材料、组织沟通回复，或练习情境表达的用户。进入工作台后先选择工作区和旅伴，在原生 Agent 聊天中处理任务；七位旅伴为毛毛姐、晴公主、静静子、陈大发、Luke、羊羊、爽子，提供不同的表达风格。

### 1. 起草和整理日常工作材料

把已有资料、任务要求或零散想法交给 Agent，例如“把这些项目进展整理成周报，列出已完成、风险和下周计划”，或“根据这份活动需求起草执行方案，列出步骤与待确认事项”。可继续要求补充、缩短或调整语气，得到可审阅和修改的周报、方案、摘要或任务清单。文件读取、检索和其他工具由 DSH 原生 Agent 按用户配置与权限执行；工作台提供角色表达和工作区入口，实际任务效果取决于所用模型及工具。

### 2. 遇到不好开口的事，先写一段能用的回复

描述沟通对象、事情经过和自己想守住的边界，或贴入需要回复的消息。例如“同事临时把额外任务交给我，我今天排满了，帮我说明排期并请他确认优先级”，以及“这项工作分工不清，帮我问清谁负责什么”。选择旅伴后获得对应风格的回复草稿，再追问“温和一点”“更直接”“缩短到两句话”，形成适合自己发送的版本；发送由用户自行决定。

### 3. 拆解一句话为什么这样说，帮助选择表达方式

使用“花学拆解”理解回复的表面意思、背后的诉求、关系上的取舍与可能代价。例如比较“直接拒绝”和“说明条件后再答应”各自会传递什么信息，帮助用户判断采用哪种表达。也可以要求只给回复、不做分析。这里提供的是表达参考，不把模型对他人动机的推测当成事实。

### 4. 在多人情境中练习接话，并回看选择的影响

进入“第八位嘉宾”，选择预设场景和开场回应，或输入自己的说法，参与多人情境续演。适合练习面对分歧时如何表态、缓和冲突或提出下一步安排。阶段结果整理当前局面、发言影响、人物态度、未解决的矛盾和后续走向；结果之后可以继续往下聊，也能向上翻阅此前对话，回看自己的回应带来了什么变化。该功能是情境演绎，不代表对真实人物或现实结果的预测。

### 使用过程与辅助功能

点击侧栏工作台进入工作区与七人选择页，选择后进入聊天；支持切换旅伴、新建会话、保留会话草稿、自定义背景和游戏历史回看，方便把同一项工作的讨论接着进行。也可进行日常闲聊或倾诉。

## 目录

- outputs/huaxue-workbench：业务 Host 与客户端、人物规则、场景资料及界面资源。
- outputs/dsh-local-workbenches：本机工作台宿主适配，非官方 SDK。
- work：可重建的客户端模板、构建工具及原生宿主补丁生成工具。

## 构建与测试

使用 Node.js 24（支持 JSON import attributes）：

```sh
npm run build
npm test
```

构建不需要模型密钥，不修改已安装应用。安装版 Cordis/SystemPrompt 集成和完整 UI 的历史实机结果见 VALIDATION.md，不把本源码包的纯逻辑测试等同于全量实机测试。

## 安装接入边界

当前使用本地 profile 链接插件，同时对 Desktop 六个原生客户端模块做适配：sidebar、session-controller、workspace、layout、conversation、agent-preset。未获得官方稳定扩展接口；不应直接用于其他版本。

在独立测试用 Desktop 0.8.2 环境中，将两个 outputs 包通过 profile dependencies 引入，在 Cordis profile 中加载这两个包，并把包名加入 dsh.profile.bundles。业务包加载依赖 settings、systemPrompt、workbenches；两个包的运行依赖由同版本 Desktop 提供。游戏还依赖既有 huashao2 preset：安装前需准备这一 preset，本材料没有把其本机私人 profile 配置导出。普通工作台新会话使用 standard preset。

原生补丁生成工具：设置环境变量 DSH_DESKTOP_APP 为安装目录的 resources/app，然后执行 `node work/build-local-workbenches.mjs`。此工具生成补丁而不直接安装。`work/install-local-workbenches.mjs` 是现有 web profile 的迁移工具，前提是业务包与 huashao2 preset 已注册；不宣称它是全新机器的一键安装器。先备份对应 profile 和原生文件，在退出 Desktop 后应用并重新启动 Harness。补丁内容和版本必须先核对，不覆盖未知宿主文件。

本轮没有对另一台全新机器进行安装验收。正式市场接入前，需由维护者确认宿主接口并补齐可分发安装流程。

## 使用

点击工作台进入选人页，选择工作区后选择旅伴。聊天页可切换旅伴、选择工作区、新建会话和设置背景。原会话及其草稿保留。游戏支持续演、阶段结果和历史回看；结果跟随产生它的消息，续聊按时间向下追加。

点击工作台入口先选人是作者产品交互，偏离投稿清单的“入口恢复最近会话”；点击具体历史会话仍打开对应会话。入口位置暂保留当前侧栏位置，后续由官方市场宿主统一接管。

卸载为停用入口，保留会话、配置与文件。完整撤回本地适配需恢复六个原生文件和 profile 的迁移前备份，不删除业务资料。

## 权限与费用

普通 Agent 沿用用户 DSH 模型及访问权限，可能使用文件、Shell、网络工具。游戏规则要求仅进行对话。模型消耗按用户自己的供应商收费；本工作台无额外计费后端。凭据通过 DSH 配置，本仓库不提供、不收集凭据。
